Selections · List Setup

Sign in with your Bellweather Microsoft account to check or create the selections lists.

What this page does

Creates the five selections lists on BWCore, with every column and index the selections tool expects. Column names follow BuilderTrend's structure.

It only adds. It never deletes, renames, or changes an existing list or column, and it never touches list items. If a column exists with the wrong type, it's reported here for a person to fix.

Import a job

Loads one job's selections from a canon file (JOB.canon.json, converted from the BuilderTrend print export). The file is read in your browser and goes only to SharePoint.

Adds allowances, selections, choices, line items and comments. Records already in SharePoint for that job (same title) are skipped unless you tick Also update existing records; then only fields that changed are written. It never deletes, and it runs only when the check above is all green. Safe to run again.

One check per list: version history

The page can't read or set version history. On BWCore, new lists already start with the right settings, so this is a check. For each of the five lists:

  1. Open the list on BWCore, then gear icon → List settings → Versioning settings.
  2. Confirm: Require content approval = No, Create a version each time you edit an item = Yes, Keep the following number of versions = 50.
  3. If anything differs, change it and click OK. Otherwise click Cancel.
