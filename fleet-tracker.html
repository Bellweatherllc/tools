Fleet Setup

1. SharePoint lists (BWCore)

Checking…

Creates CORE_FleetVehicles, CORE_FleetSettings and the FleetRole column on CORE_TeamMembers. Safe to run again; it only adds what’s missing.

2. Import data

Choose the Fleet snapshot .html file (Bellweather-Fleet-Snapshot-….html). It holds every field, including decal sizes and placard period that the .xlsx export leaves out. Vehicles and settings already in SharePoint are skipped, never overwritten.

3. Anchor file links

Registration and insurance-card links came in as folder paths, which break when a file moves. This looks up each file and stores its SharePoint item id so the link keeps working.

4. Give people access

Open Team Members → Access and set Fleet to Admin (edit) or Member (view only). Blank = no access.
