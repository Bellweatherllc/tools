# Bellweather 2026 Project Planning Guide (web version)

Link-only page. It is hidden from search engines (see the `robots` tag in index.html).

## Annual update
Open `index.html` and search for `ANNUAL UPDATE`. There are two spots:
1. The cover title year ("2026 Project Planning Guide"), plus the year in the `<title>` and `og:title` tags near the top.
2. The "Project Comparisons (2024-2025)" heading and the five price ranges beneath it.

Only change the text between the tags. Leave the `data-project="…"` values as they are.

## Project-specific links
Add `?project=` to the end of the link to highlight one range:
- `?project=kitchen`
- `?project=bathroom`
- `?project=whole-home`
- `?project=addition`
- `?project=basement`

## Files
- `index.html` – the page
- `images/` – cropped, compressed photos and `link-preview.jpg` (the image shown in text and email link cards)

Fonts and logos load from the existing style guide at bellweatherllc.github.io/tools/.
